### How I work

```text
idea ──▶ spec ──▶ AI agents build ──▶ shipped ──▶ measured ──▶ next version
```

Small, fast loops. I own the product and the result; the agents write most of the code, and I review,
test and ship. Same method for growth: dozens of creators, around thirty videos a day, millions of views.
